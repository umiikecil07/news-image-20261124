A one-page news front page for Tuesday 24 November 2026, drawn by a Python program: Nvidia brings back Jensen Huang as markets rebound, plus the day's top stories from the Gulf, Libya, Berlin and Singapore.

## Run it

```sh
python3 main.py
```

This writes `entry.png` to `/output` (set `MAKEFUN_OUTPUT_DIR` to change the output folder). It draws the page with Pillow from the story constants in `data.py`; if Pillow is ever unavailable it copies the shipped `entry.png` instead, so the output is the same image either way.
